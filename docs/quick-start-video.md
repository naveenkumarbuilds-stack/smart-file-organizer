# Smart File Organizer — Quick-start video

English synthetic narration with real captured screens and clearly labelled illustrated steps.

## 00:00 — Smart File Organizer

Welcome to Smart File Organizer. This guide shows you how to download the Windows app from GitHub, review your files, organize them, and use Undo.

## 00:12 — 1. Open the GitHub project

Open the GitHub project using the link in this video's description. On the right, under Releases, choose Smart File Organizer version one point zero point zero.

## 00:26 — 2. Download the Windows installer

In the release page, open Assets. Click Smart File Organizer, one point zero point zero, Windows x sixty four, dot E X E. This installer includes Java. You do not need to install Java separately.

## 00:45 — 3. Install and launch

Open the downloaded installer and follow its setup prompts. Then launch Smart File Organizer from the Start menu. This release is unsigned. If Windows or your organization blocks it, ask your administrator for help.

## 01:03 — 4. Choose a sample folder

For your first try, use a sample folder containing copies of a few files. Click Choose folder, select your sample folder, and wait for the preview. Only files directly inside the chosen folder are organized.

## 01:21 — 5. Review the preview

Review the File, Category, and Destination columns. For example, a text file goes into Documents, while a photo goes into Images. Existing names are protected with numbered suffixes.

## 01:37 — 6. Exclude anything you want to keep

Use the Include checkboxes to choose which files move. In this example, b dot j p g is unchecked, so it stays where it is. Only a dot t x t will move.

## 01:52 — 7. Organize the selected files

Click Organize. A confirmation dialog shows how many files will move and how many folders they will use. Check those counts, then click O K to begin. The progress bar tracks the operation.

## 02:08 — 8. Check the result

When organization finishes, read the moved, skipped, and failed counts. In our example, a dot t x t is now inside Documents, and the unchecked photo stays in the original folder. The preview refreshes automatically.

## 02:26 — 9. Undo the last organization

To reverse the last organization, click Undo last organization and confirm. The app restores eligible files to their original locations. Its undo history is saved on disk, so it also works after closing and reopening the app.

## 02:44 — 10. Understand skipped files

If a file is missing, edited, locked, or its original location is occupied, the app may skip it. Check the message and use Skipped files for scan exclusions. Starting a new organization replaces the previous undo history.

## 03:03 — Ready to try it?

You are ready to try Smart File Organizer. Download it from the release link, test it on sample files, and share the guide with a friend. For help or suggestions, use Issues on the GitHub project.
